## 0. 개념 및 기술 조사

* AI Agent 분야의 **Graph Engineering**, Loop Engineering, Harness Engineering을 조사하고 Harnest의 용어와 실행 모델을 명확히 정리한다.
* LangGraph 등 그래프 기반 Agent Runtime, MCP 최신 표준, 시각적 Node Editor와 확장형 Component 시스템의 권장 방식을 조사한다.
* Harnest는 범용 자동화 도구가 아니라, 사용자가 UI에서 하네스 구성요소와 실행 구조를 직접 설계하는 **Visual Graph Engineering Platform**이라는 방향을 유지한다.

## 1. 확장형 Component 시스템

* Component 정의, Port, 설정 Schema, Validator, Inspector UI와 Executor를 등록형 구조로 확장한다.
* 새로운 Component를 Core와 Studio의 대규모 수정 없이 추가할 수 있게 한다.
* 기본 노드에 Context, Memory, Local Tool, MCP Tool, Router·Condition, Evaluator를 추가하고 Custom Component도 등록할 수 있게 한다.

## 2. Graph Engineering

* 단순 직선 연결을 넘어 조건 분기, 병렬 실행, fan-out·fan-in, 상태 전달, 합류, 재사용 가능한 Subgraph를 설계·실행할 수 있게 한다.
* Canvas에서 각 Edge의 조건과 데이터 흐름을 설정하고 잘못된 연결, 도달 불가능 노드, 잘못된 합류와 상태 충돌을 실행 전에 검증한다.
* 그래프 실행 과정과 각 Node의 입력·출력·상태 변화를 Trace에서 확인할 수 있게 한다.

## 3. Loop Engineering

* Back Edge 또는 Loop 구성요소를 통해 반복 실행 구조를 시각적으로 설계할 수 있게 한다.
* 반복 조건, 종료 조건, 최대 횟수, Timeout, 비용·Token 제한, 상태 갱신, Evaluator 결과에 따른 재실행을 지원한다.
* Tool 사용 반복, 계획→실행→검증, 생성→평가→개선 같은 Agent Loop를 구성할 수 있게 한다.
* 무한 반복과 무제한 재시도를 차단하고 각 반복 회차를 Trace와 Studio에서 명확하게 표시한다.

## 4. Tool·MCP·Context 실행

* Local Tool과 MCP `stdio`·Streamable HTTP 연결, Tool 조회·선택·호출과 오류 처리를 구현한다.
* 파일·디렉터리·정적 텍스트 Context와 기본 Memory를 지원한다.
* Agent가 연결된 Tool과 Context만 사용할 수 있게 하고 Tool 호출·Context 사용 내역을 Trace에 기록한다.

## 5. Studio 고도화

* Component 검색·분류, Drag & Drop, Typed Port, 조건 Edge, Loop·Subgraph 편집, Inspector 자동 생성과 실시간 Validation을 구현한다.
* 실행 중인 Node·Edge·반복 회차를 Canvas에서 표시하고 결과, 오류, Trace와 Test를 자연스럽게 확인할 수 있게 한다.
* Canvas에서 만든 그래프가 저장·재로드·CLI 실행 후에도 의미적으로 동일해야 한다.

## 6. 실행·평가·저장

* 조건 분기, 병렬 실행, Loop, 취소, Timeout과 안전한 Retry를 Core에서 실제 실행한다.
* Output Schema, 문자열·Tool 호출·Latency·반복 횟수 기반 Evaluator와 Test Runner를 확장한다.
* Trace와 사용량을 프로젝트 단위로 영속 저장하고 Studio와 CLI에서 조회할 수 있게 한다.
* 대표 RAG, MCP Tool Agent, 평가 기반 개선 Loop 예제를 제공한다.

## 7. 검증 및 문서

* 기존 보안 정책과 Adapter 확장성을 유지한다.
